# EAH // Cuadros Artísticos

Aplicación web de pedidos para **EAH Cuadros Artísticos**, un taller de cuadros artísticos en resina epoxi.

## ¿Qué hace?

- Encuesta interactiva tipo chat (embudo de ventas)
- Galería de productos con slider de fotos
- Carrito de compras con folio único
- Rastreo de pedidos y envío por WhatsApp
- Formulario de contacto

## Tecnologías

HTML, CSS y JavaScript puro (sin frameworks, sin backend).
